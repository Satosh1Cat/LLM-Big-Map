# Code of Conduct

Be precise. Be kind. Argue about sources, not people.

- Fact disputes: cite a URL and a date.
- No harassment, slurs, or personal attacks.
- No spam, shilling, or unpaid advertorials disguised as chapters.
- Security: never paste API keys, cookies, or private transcripts.

Report conduct issues to the maintainers via GitHub. For a fact error, use the `fact-error` issue template instead.

This is a short local policy. It is not the full Contributor Covenant; PRs to adopt a longer text are welcome.
